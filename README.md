# 🎨 Guia de Identidade Visual & Design System — Itaú

Documentação dos **design** para o entendimento de Contraste, Tipografia, Variáveis de Cor, Escala de Fontes, Logotipo e Teoria das Cores.

---

## 🎯 Sobre o Projeto

Este repositório padroniza os elementos visuais essenciais para interfaces digitais, garantindo consistência, acessibilidade e agilidade no desenvolvimento.
